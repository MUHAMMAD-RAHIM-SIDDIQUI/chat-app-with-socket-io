# Real-Time Messaging App

A real-time chat application where messages appear instantly, without refreshing the page. Built to show how live, two-way communication works in a modern web app.

**Live Demo:** https://socketio-frontend.netlify.app/login

## What it does

- **Instant messaging** - Send and receive messages in real time.
- **Online status** - See who is online right now.
- **Live updates** - New messages and activity appear as they happen, powered by Socket.io.
- **User accounts** - Sign up and log in to start chatting.

## Tech Stack

React.js, Node.js, Express.js, Socket.io, MongoDB

## Run it locally

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm run dev
```

Make sure MongoDB is running and the backend URL is set in the frontend environment variables before you start.
